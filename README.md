# Автоматическая диагностика и многоуровневая оптимизация LLM-агентов на основе анализа траекторий выполнения

Годовой проект 1 курса магистерской программы **«Искусственный интеллект»**, 2026/27 учебный год.

## О проекте

Итоговый продукт — система для автоматической оптимизации LLM-агентов.

В систему загружается агент вместе с его конфигурацией, промптами, описаниями инструментов и информацией о структуре, а также набор задач, на которых можно оценить качество его работы.

В качестве основной предметной области используется агент для работы с документами: он ищет информацию в базе документов, анализирует найденные данные и формирует ответы на пользовательские запросы.

## Как работает система

Система запускает агента на подготовленных задачах и сохраняет:

- итоговые ответы;
- полные траектории выполнения;
- промежуточные шаги;
- вызовы инструментов;
- результаты вызовов;
- возникающие ошибки.

Результат каждого запуска оценивается отдельным модулем по заданным метрикам качества.

Помимо итоговой оценки, система анализирует сам процесс работы агента. Диагностический модуль определяет, на каком этапе возникла ошибка, с каким компонентом она связана и что могло стать её причиной. На основе этой диагностики выбирается подходящий способ исправления.

После каждого изменения новая версия агента снова проверяется на наборе задач и сравнивается с предыдущей. Изменения, которые действительно улучшают качество на отложенных данных, сохраняются, неудачные изменения отклоняются. Оптимизация продолжается до тех пор, пока качество растёт или пока не выполняется заданное условие остановки.

## Уровни оптимизации

### 1. Текстовые параметры

Изменяются промпты, описания инструментов и другие текстовые параметры агента.

### 2. Структура и обвязка

Изменяются управление контекстом и памятью, проверки, повторные попытки, маршрутизация и другие дополнительные компоненты.

### 3. Архитектура и программная реализация

Подключается кодовый агент, который может менять архитектуру и программную реализацию: добавлять новые узлы, инструменты и связи между компонентами.

## Режимы работы

Система поддерживает несколько режимов работы:

- можно выбрать только один тип оптимизации, например изменение промптов или структуры;
- можно разрешить несколько уровней одновременно;
- предусмотрен полностью автоматический режим, в котором система сама определяет причину ошибки и выбирает подходящий уровень изменения.
